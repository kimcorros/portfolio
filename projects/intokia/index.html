Overview

What Intokia does

Intokia is a Security Token Offering (STO) platform that lets issuers tokenize real-world assets and offer them to investors under regulatory compliance. Real investors. Real assets. Real money flowing through a verified onboarding pipeline.

Working in regulated fintech means every form, every API endpoint, and every admin action carries compliance weight. That shaped how I built the platform: tight integration with KYC providers, careful state machines for investor onboarding, and an admin dashboard that gives operators visibility into every step of the verification flow.

What I Built

Key contributions

End-to-end product features

Shipped features from API design through Vue/Nuxt UI — REST endpoints, validation, business logic, and admin tooling spanning frontend and backend.

Laravel Filament admin dashboard

Built issuer and investor workflows, data visualizations, tables, and forms powering daily platform operations.

KYC / AML verification pipeline

Integrated Sumsub, Shufti Pro, and Muinmos for regulated investor onboarding — identity verification, document checks, and compliance status tracking.

Keycloak SSO integration

Centralized authentication and single sign-on across the platform — role-based access, token lifecycle, and session management.

Data visualizations & reporting

Built dashboard components for tracking investor activity, asset performance, and compliance metrics across the platform.

REST API design

Designed and implemented endpoints powering the investor portal, admin dashboard, and KYC workflows with consistent validation and error handling.

Regulated fintech, real money

This wasn't a side project or a demo — Intokia is a live platform with real investors moving real capital into tokenized assets. Every KYC integration, every admin workflow, every authentication boundary was built with regulatory compliance in mind. Working at this level meant treating production reliability and audit-readiness as defaults, not afterthoughts.
